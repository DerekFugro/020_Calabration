Rules
If GUI: use dark mode
If GUI: enforce GUI_Coding_Standards.md (Questions/GUI_Coding_Standards.md)

Every QWidget subclass must use the 5-method init pattern
Every widget must have a named instance variable
No business logic in create* methods
Dynamic widgets use factory + populate + clear pattern
Ask if anything is unclear before starting
Write a plan grouped into phases before writing any code
List all software and extensions with versions for each phase
Between phases: run full test suite, report results, wait for "proceed"
Do not advance to next phase if any tests fail
If software cannot be installed or version conflict found: stop and report before continuing

First tasks when coding begins
Read GUI_Coding_Standards.md if this is a GUI project
Read and list all required software and extensions with versions
Verify version compatibility via web search
Create the environment and install all dependencies
Report setup complete with version summary and wait for "proceed"
